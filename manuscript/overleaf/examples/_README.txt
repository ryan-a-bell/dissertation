
This folder contains additional latex thesis documents: 

* multi_appendix.tex: includes format for theses with multiple appendices
* exec_sum_with_refs.tex: includes format for adding references to the executive summary
* thesis_classified.tex: includes format for classified theses
* class files: tools and examples for classified theses

If you have a thesis that requires these additional features, you can merge features between these two files yourself. 

See the top of each file for instructions.
