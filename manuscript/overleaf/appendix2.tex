This appendix provides the task configurations for evaluating \acp{llm} on the variants of SysEngBench via \texttt{lm-evaluation-harness}. Including these files ensures complete reproducibility of the methodology described in Chapter~\ref{ch:materials_methods}. 

This section includes the lm-evaluation-harness task configurations used
for \ac{mcq} and \ac{osq} evaluations. These YAML files define 
prompt templates, parsing rules, metrics, stopping conditions, and dataset 
sources.
